# Fellaswimming

Website for Fellaswimming — a swim school in Sidoarjo, Indonesia. Lead-generation site with a public landing, 3-step registration form, educational articles, and an admin dashboard for staff to manage leads and content.

## Stack

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS v4 (CSS-first `@theme`)
- shadcn-ui v4
- Supabase (Postgres + Auth + Storage + RLS)
- TanStack Query v5
- Tiptap 3 (article CMS)
- Deployed on Vercel

## Status

Planning complete via PLAID; implementation not yet started. See `docs/product-roadmap.md` for the phased build plan (82 tasks across 6 phases, MVP target 8–10 weeks).
